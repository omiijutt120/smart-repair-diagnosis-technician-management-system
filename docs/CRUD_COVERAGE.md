Core historical fields cannot be arbitrarily edited. This implements the PRD's safe CRUD exceptions rather than allowing invalid financial/stock/status changes.

Archive metadata and per-record audit logs store the actor, UTC time and reason. The 40 domain tables are separate from Alembic's migration-version metadata table.
